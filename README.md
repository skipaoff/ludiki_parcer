# Terminal Ludik

[![CI](https://github.com/skipaoff/ludiki_parcer/actions/workflows/ci.yml/badge.svg)](https://github.com/skipaoff/ludiki_parcer/actions/workflows/ci.yml)

Локальный торговый терминал межбиржевого ценового гэпа на бессрочных фьючерсах.

Как работает:
- вилки появляются в ленте с ROI, посчитанным по стакану на твой размер сделки;
- пара открывается одной кнопкой: одинаковое количество токенов, рыночные ордера на обеих биржах;
- открытые пары мониторятся в реальном времени и закрываются одной кнопкой;
- все вилки, открытые и неоткрытые, пишутся в базу для статистики.

**Старт:** Binance и MEXC. **Потом:** остальные биржи, разделы «Фандинг» и «Разлоки».

**Статус:** этап 0 готов. Терминал запускается одной командой на Windows 11: локальная база, сервер, интерфейс с вкладками и журналом. Подключения к биржам пока нет — это этап 1.

## С чего читать

1. [`docs/PLAN.md`](docs/PLAN.md) — полный план: решения, экраны, архитектура, формулы, база, дорожная карта до MVP и дальше. Отличия Windows — раздел 4.6.
2. [`docs/EXCHANGES.md`](docs/EXCHANGES.md) — эндпоинты и особенности Binance, MEXC и следующих бирж, с пометками «проверено» или «проверить».
3. [`reference/crypto_pars/README.md`](reference/crypto_pars/README.md) — наработки из парсера: что перенесено, что исправлено, почему старую логику нельзя торговать как есть.

## Запуск

```bat
ludik.cmd
```

Команда при первом запуске ставит зависимости Python и собирает интерфейс, затем поднимает локальный PostgreSQL, применяет миграции, запускает сервер на `http://127.0.0.1:8765` и открывает браузер. Остановка — `Ctrl+C` в окне консоли. Повторный запуск, пока терминал работает, просто открывает его в браузере.

Флаги: `--no-browser`, `--config путь\к\config.toml`. Настройки по умолчанию — `config.example.toml`; чтобы поменять, скопируйте его в `config.toml`.

## Окружение (Windows 11)

Нужно один раз:

| Что | Как |
|---|---|
| Python 3.13 и uv | `winget install -e --id Python.Python.3.13 --source winget --scope user` и `winget install -e --id astral-sh.uv --source winget --scope user` |
| Node.js 24 (только для сборки интерфейса) | `winget install -e --id OpenJS.NodeJS.LTS --source winget` |
| PostgreSQL 18 + TimescaleDB 2.30 | архив `postgresql-18.6-3-windows-x64-binaries.zip` от EDB и `timescaledb-postgresql-18-windows-amd64.zip` из релиза TimescaleDB 2.30.0, распакованы в `C:\projects\ludik-data\pgsql`; кластер `C:\projects\ludik-data\pgdata`, пароль в Диспетчере учётных данных (`ludik` / `postgres:ludik`). Подробности — `docs/PLAN.md`, раздел 11.1 |

Данные терминала лежат рядом с репозиторием, в `C:\projects\ludik-data`: бинарники и кластер PostgreSQL, буфер записи `spool`, логи `logs`.

Если антивирус перехватывает HTTPS (на машине разработки это Avast), uv настроен на системные сертификаты в `pyproject.toml`, а для npm нужен `NODE_OPTIONS=--use-system-ca` — `ludik.cmd` выставляет его сам. Для доменов бирж перехват нужно выключить в антивирусе до этапа 1.

## Структура

```
docs/                   план и заметки по API бирж
app/
  main.py               точка сборки: собирает компоненты и управляет запуском и остановкой
  config/               несекретные настройки из config.toml
  keystore/             ключи и пароли в Диспетчере учётных данных Windows
  system/               event loop, логи с маскировкой секретов, запрет сна
  journal/              журнал событий для интерфейса и таблицы events
  storage/              локальный кластер, миграции, пул, очередь записи с буфером на диске
  api/                  FastAPI: REST и WebSocket до браузера
  core/                 чистые функции без I/O, часов и случайности
    schemas.py          стакан, инструмент, комиссии — всё в токенах
    symbols.py          монета и множитель контракта, проверка «та же ли это монета»
    qty.py              одинаковое количество токенов на обеих биржах
    vwap.py             средняя цена исполнения по стакану
    roi.py              ROI входа, ёмкость, спред выхода, PnL сейчас, ликвидация
    episodes.py         жизненный цикл вилки: лента → отслеживание → схождение
    legs.py             что делать при отказе, частичном исполнении или неизвестном статусе ноги
    actions.py          намерения, которые исполняет диспетчер
    links.py            ссылки на страницу торговли
  exchanges/
    base.py             контракт адаптера биржи (черновик)
web/                    интерфейс: React, Vite, TypeScript
db/
  001_schema.sql        схема PostgreSQL 18
  002_timescale.sql     сжатие, хранение и агрегаты TimescaleDB
reference/crypto_pars/  копии модулей парсера для справки
tests/                  тесты: ядро, конфиг, ключи, журнал, запись, API
.github/workflows/      CI: тесты на Ubuntu и Windows, сборка интерфейса, схема на PostgreSQL 18 + TimescaleDB
ludik.cmd               запуск одной командой
```

Код организован по канону: у каждого файла паспорт (VFP / Changes when / Anti-goal), решения — чистые функции, побочные эффекты — только в исполнителе.

## Проверка

```bat
uv run pytest
```

Интеграционный тест миграций нужен живой PostgreSQL с TimescaleDB и пустая база в `LUDIK_TEST_DSN`; без переменной он пропускается.

```bat
set LUDIK_TEST_DSN=postgresql://user:password@127.0.0.1:5432/ludik_test
uv run pytest -m db
```

Интерфейс:

```bat
cd web
npm ci
npm run build
```

Для разработки интерфейса: терминал запущен, в `web` выполнить `npm run dev` — Vite на `http://127.0.0.1:5173` проксирует API и WebSocket в терминал. Токен сессии передаётся так же, во фрагменте `#t=`.

CI повторяет все проверки при каждом пуше в `main` и в каждом pull request.

## Как работать с репозиторием

- **Где что решено.** Все решения и дорожная карта — в `docs/PLAN.md`. Если решение меняется, план правится в том же PR, что и код.
- **Ветки.** Одна ветка на этап или задачу (`stage-1-exchanges`), в `main` через pull request с зелёным CI.
- **Паспорт файла.** Новый файл начинается с паспорта: VFP / Changes when / Anti-goal.
- **Где живут решения.** Решения — чистые функции в `app/core/` с тестами. Сеть, база и время — только в оболочке.
- **Миграции.** Применённый файл `db/NNN_*.sql` не редактируется: изменение — новый файл со следующим номером. Терминал сверяет контрольные суммы и не стартует запись при расхождении.
- **Секреты и живые биржи.** Никаких ключей, `.env` с настоящими значениями и дампов базы в git. Никаких вызовов живых бирж в тестах.
- **Непроверенные факты.** Факты об API бирж записываются в `docs/EXCHANGES.md` с пометкой, откуда они взяты.

## Безопасность

- API-ключи хранятся только в Диспетчере учётных данных Windows. В репозитории, базе и логах их нет и не будет.
- Сервер слушает только `127.0.0.1`, требует токен сессии и проверяет заголовки Host и Origin.
- Логи маскируют значения из хранилища ключей и поля вида `apiKey`, `signature`, `listenKey`.
- `.gitignore` закрывает `.env*`, `config.toml`, локальные базы и логи.
- Ключи на биржах выпускаются без права вывода средств.
