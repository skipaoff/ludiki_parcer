# Наработки из парсера crypto_pars

Здесь лежат копии модулей Telegram-парсера «Лудикопарсер». Они без изменений взяты из коммита `fdb8edb` (27.07.2026), этот код работал на сервере.

**Это справочник, а не зависимость.** Терминал эти файлы не импортирует. Всё, что пригодилось, перенесено в `app/core/` с исправлениями, в каждом перенесённом модуле есть пометка «Ported from».

Telegram-логика (`parser.py`) и хранение подписчиков (`subscriber_store.py`) сюда не скопированы: для терминала они не нужны.

## Что где лежит

| Файл | Что внутри | Когда понадобится терминалу |
|---|---|---|
| `price_gap.py` | Сканер ценового гэпа по 11 биржам: публичные REST-эндпоинты тикеров, нормализация тикеров, фильтр ликвидности, двойная проверка через 5 с, ссылки на биржи | Сейчас как справочник эндпоинтов. Нормализация и ссылки уже перенесены |
| `mark_gap.py` | Отклонение mark/fair от last на Binance, Bybit, MEXC | Эндпоинты mark цены; сверка индексов в `app/core/symbols.py` |
| `funding_sources.py` | Ставки фандинга 12 бирж, приведение к 8 часам, защитный предел 4% в час | Раздел «Фандинг» и колонка стоимости удержания после MVP |
| `funding.py` | Поиск фандинг-вилок между биржами, фильтры, формат | Раздел «Фандинг» |
| `token_unlocks.py` | Календарь разлоков CryptoRank, расчёт размывания circulating supply, фильтр по числу бирж с фьючерсами | Раздел «Разлоки» |
| `rankings.py` | Ранги CoinGecko, тиры A/B/C, кеш с частичным обновлением | Фильтр по тиру монеты после MVP |

## Что перенесено в терминал и что исправлено

| Было в парсере | Стало в терминале | Исправление |
|---|---|---|
| `price_gap.py::normalize` (стр. 69) | `app/core/symbols.py::parse_symbol` | Множители `1000PEPE`, `1000000MOG`, `1MBABYDOGE`, `kPEPE` разбираются, а не выбрасываются. Проверка Hyperliquid `k` учитывает регистр (парсер выбрасывал KAVA, KSM и любые монеты на K). USDC и USD контракты не проходят |
| `SYMBOL_ALIASES` в `funding_sources.py` | `TOKEN_ALIASES` в `symbols.py` | Без изменений: XBT → BTC |
| `price_gap.py::exchange_url` (стр. 33) | `app/core/links.py::trade_url` | Ссылка строится по сырому символу биржи, поэтому работает и для `1000PEPEUSDT` |
| Разница `last` цен в `find_gaps` | `app/core/vwap.py`, `app/core/roi.py` | Цена входа — средняя по стакану на заданный размер, а не последняя сделка |
| `len(sym_prices) < 3` в `find_gaps` (стр. 374) | `same_asset_verdict` в `symbols.py` | Из двух бирж третью цену для сверки не взять, поэтому одинаковость монеты проверяется по индексным ценам |

## Почему логику гэпа из парсера нельзя торговать как есть

1. **Цена последней сделки вместо стакана.**
   - `lastPrice` на Binance, Bybit, MEXC, BingX, Aster (стр. 103, 119, 163, 192, 249);
   - `mark_price` на Variational (стр. 280);
   - `midPx` на Hyperliquid (стр. 303).

   Три разных типа цены сравниваются между собой, а реальный вход идёт по ask и bid.
2. **Ликвидность по самой сильной бирже.** `_update_liq` хранит максимум объёма по всем биржам (стр. 64). Монета с $100M на Binance и $5k на мелкой бирже проходит фильтр, хотя вторая нога неторгуемая. В терминале объём берётся по слабой ноге.
3. **Выбрасываются пары с множителем.** `if s[0].isdigit(): return None` (стр. 79) убирает `1000PEPE`, `1000SHIB` и похожие. Среди них бывают вилки.
4. **Hyperliquid.** `s.startswith("K")` после перевода в верхний регистр (стр. 81) выбрасывает все монеты на K, а не только `kPEPE`-подобные.
5. **Скан раз в 30 минут и подтверждение через 5 секунд** (`scan_price_gaps_confirmed`). Для торговли нужны стаканы в реальном времени, см. `docs/PLAN.md`, раздел 5.
6. **Глобальное изменяемое состояние.** Словарь `_liquidity_cache` очищается в начале каждого скана. Два параллельных скана испортят друг другу данные.
7. **Aster: отдельный запрос открытого интереса на каждую монету** (`_fetch_aster_oi`). При подключении Aster к терминалу нужен пакетный источник.

## Что стоит взять как приём

- **Параллельный опрос бирж с повторами:** `_fetch_with_retry` с нарастающей паузой и `asyncio.gather`. Упавшая биржа не роняет скан.
- **Частичное обновление кеша** в `rankings.py`: если часть страниц не пришла, старые данные сохраняются, и через 5 минут идёт повторная попытка.
- **Приведение фандинга к одному периоду:** `rate_8h = rate * 8 / interval_hours` и годовая ставка Variational `rate * 100 * 8 / 8760` в `funding_sources.py`. Плюс защитный предел 4% в час против мусорных значений.
- **Размывание при разлоке:** `unlock_tokens / circulating_supply * 100` в `token_unlocks.py`, и фильтр «фьючерсы есть минимум на N биржах».
